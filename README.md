# 🎲 Sorteador de Números

Este é um projeto interativo para **sortear números aleatórios** com base em um intervalo definido pelo usuário. Conta com uma interface amigável e moderna, construída com HTML, CSS e JavaScript, ideal para aplicações educacionais ou uso recreativo.

## 📌 Objetivo

Desenvolver uma aplicação web que permita ao usuário sortear uma quantidade definida de números únicos dentro de um intervalo.

## 🚀 Funcionalidades

- Sorteio de números únicos dentro de um intervalo.
- Verificação de intervalos válidos e quantidade solicitada.
- Interface com botões interativos para sortear e reiniciar.
- Validação de entrada de dados com mensagens informativas.

## 📷 Layout da Interface

A interface conta com:
- Um campo para definir a quantidade de números a serem sorteados.
- Campos para informar o número inicial e final do intervalo.
- Botões de **Sortear** e **Reiniciar**.
- Exibição clara dos números sorteados.

> O design é responsivo e exibe uma imagem de astronauta em telas grandes.

## ▶️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/GustavoMarques22/SortearNumero.git
   ```
2. Abra o arquivo `index.html` em seu navegador.
3. Informe os dados desejados e clique em **Sortear**.

## 🧠 Lógica de Sorteio (JavaScript)

- Utiliza `Math.random()` para gerar números aleatórios.
- Garante que não haja repetições com checagem no array de resultados.
- Mensagens de erro ajudam na usabilidade.
